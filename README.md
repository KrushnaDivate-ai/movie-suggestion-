# CinePick — Movie Suggestion Website

A responsive, static movie suggestion website with genre and mood filters, search, a random surprise pick, and a local watchlist. It uses a built-in demo movie collection and does not require an API key or backend.

## Run locally
Open `index.html` in your browser.

## Deploy to Vercel
1. Upload the project folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (or leave the default if it detects static files).
4. Deploy.

## Deploy with GitHub Pages
1. Push `index.html` to the root of a GitHub repository.
2. Go to **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the public Pages URL to appear.

After deployment, copy the public URL. A QR code can be generated from that URL so people can open the site by scanning it.
